# Phanish Chava — Portfolio

A static, responsive personal portfolio designed for GitHub Pages. No build step or framework is required.

## Publish on GitHub Pages

1. Create a repository, for example `phanishchava.github.io` (or any repository name).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select your main branch and `/ (root)`.
4. Your site will be available at the GitHub Pages URL shown by GitHub.

## Customize

- Profile image: `assets/profile.jpg`
- Publication data and links: `script.js`
- Main copy and profile links: `index.html`
- Theme and visual system: `styles.css`

The site intentionally does **not** contain a downloadable CV link.
